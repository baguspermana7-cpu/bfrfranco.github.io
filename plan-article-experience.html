Article Experience Overhaul

Seven defects surfaced in a live review of the article pages — alignment, related navigation, callout styling, calculator standards-compliance, and data visualisation. The fix is a shared system (lands on all 27 editorial articles) plus a verified article-26 / article-27 reference pair.

Owner decisions (locked)
  • Sequencing — build the shared system + perfect the two reference articles first; batch-roll the bespoke per-article work after.
  • Slop sweep — site-wide shared-CSS overrides (extend the editorial .quote-callout language to every callout). Article heroes stay as-is this round.

01Reading column — "lurus" & justified

The 68ch measure is font-size-dependent, so the 1.14rem lead paragraph and 1rem body paragraphs computed different widths and, centered, landed on different left edges. Replaced with a single left-aligned, justified column at a fixed rem measure — prose, hero figure and tables share one left+right edge; a tier-3 hairline divides each <h2>, aligned with the hero.

Before
lead ¶ 837px @ x531 · body ¶ 734px @ x583 · h2 @ x392 — three left edges, ragged, not justified.
After
every block 744px @ x176 — one shared edge, justified, divider aligned to hero. css/rz-article-dark.css

02Related rail

A compact, sticky right rail built by js/rz-article-editorial.js from each page's existing "Continue Reading" cards (thumbnail derived from the href). 2-column grid on wide screens; collapses to the bottom grid < 1024px. Zero per-article markup edits.

03Callout de-slop

Saturated gradient fills + 3–4px borders (.info-box, .ws-insight-box, .ws-engineer-note, .ws-evidence-block) → the editorial language: flat color-mix tint + 1px hairline + a 2px semantic accent rail + one restrained shadow, scoped to the editorial register. Per documentation/design.md §2 line tiers (never 3–4px) + §3 anti-patterns.

04Calculator tooltips

The in-article .ws-calc-wrap calculator now meets TOOLTIP_STANDARD.md: all 12 inputs carry a ? help affordance and all 9 KPI cards a ⓘ tooltip with the formula / denominator / source. CSS-only hover/focus, themed to the article accent.

05Number badges

White text on saturated category-gradient ovals washed out on red/teal thumbnails. Replaced (articles.html) with one dark-glass instrument chip — hairline + mono tabular-nums slashed-zero — legible on any thumbnail in both themes.

06Interactive, source-validated charts

Owner brief: intuitive interactive charts (CNBC-style hover crosshair + tooltip), 1–2 key parameters per article, valid data with sources — "tidak ngawur, ada sumbernya."

  • Component js/rz-article-chart.js — on-brand Chart.js (signal-amber / instrument-cyan / oscilloscope-green, mono tabular axes, 0.6px grid, crosshair), theme-aware, finding-titled, with a visible Source caption + basis chip.
  • Data data/article-N/ CSV — every row carries source + basis_tag (precedent: data/fire/, data/cdu/, the 16 verified data/article-26/ files).
  • Gate tools/audit-article-charts.mjs --strict — fails any chart missing source/basisTag.
  • Reference article-26 dual-axis fluid-loss line (modelled, from worked-model-scenarios.csv); article-27 aging-workforce bar (published, AFCOM 2024).

Full spec: standarization/ARTICLE_DATAVIZ_STANDARD.md.

Reading column, dividers, related rail and callout de-slop land on all 27 editorial articles automatically via the shared CSS/JS. The bespoke remainder rolls in batches: calculator-tooltip compliance on every other in-article calculator; a free inline sourced chart for each remaining text-heavy article; per-article slop the shared overrides can't reach. Each batch re-runs the gate suite + uiux-reviewer.
