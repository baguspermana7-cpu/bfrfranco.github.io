New on ResistanceZero: How a Large Language Model Actually Works, from one token to a 1 GW campus.

If you run data centers, you run the machines that run AI. This article shows what the machine inside computes, in plain language first and then with the maths and the numbers: how text becomes tokens, how attention works, why the KV cache eats GPU memory (a 70B model needs 40 GiB for one 128K-token conversation), why mixture-of-experts models bill compute on 37B parameters out of 671B, why generating text is limited by memory bandwidth and not by FLOPs, what a 15-trillion-token training run costs in dollars and megawatt-hours, and how all of that becomes 132 kW liquid-cooled racks and tens-of-megawatt load swings.

Five calculators you can use: will the model fit, training cost and energy, tokens per second and dollars per million tokens, LoRA memory, token cost per document. Every number has a source.
