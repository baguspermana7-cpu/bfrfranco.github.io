Skill Registry ECC · Skills

Today every tool is an island. A user can't chain the PUE calculator's output into the TCO model, or feed a Decode-Lab fault into the Maintenance Workbench. ECC's skill manifest makes each tool a typed, composable node.

Today28+ tools, zero shared contract. One registry exists — the Decode Lab's detect→decode→visualize→simulate→export→validate.
BuildDefine rz-skill.schema.json (id · inputs · outputs · provenance · confidence · feeds). Write a manifest per tool. Generalise the Decode-Lab contract site-wide. Add tools/audit-skill-registry.py — fails if a tool ships without a manifest.

Rules — 100% auditor coverage ECC · Rules

Hooks → profiled CI gate ECC · Hooks

The auditors run by hand pre-ship — discipline by memory. ECC makes them event-driven and profile-gated, so the right depth runs automatically and merge is blocked on failure.

Today6 auditors invoked manually before each ship. Easy to forget; nothing blocks a bad merge.
Buildtools/rz-gate.py --profile minimal|standard|strict (mirrors ECC_HOOK_PROFILE). A GitHub Actions workflow auto-selects by changed path: docs→minimal, content→standard, calc/cockpit→strict.

Continuous-learning loop ECC · Instincts · KEYSTONE

The one layer RZ has never built — and the one that makes every other pillar compound. Two loops: how RZ is built, and what RZ serves.

TodayImprovement is manual. Feedback lives informally in memory files + the bug tracker; the AI-Maintenance KG loop is designed but unfinished.
BuildDev loop: every comment/bug/review → a confidence-scored instinct; at high confidence it evolves into a standarization/ rule + auditor. Surface loop: finish the KG cycle — closeout → kg-diff → review → retrain (the v1.41.7 KGDiff/AuditEvent contracts already exist).

RZ-Shield — adversarial accuracy audit ECC · AgentShield

AgentShield runs three agents — red-team / blue-team / synthesise. RZ's standing accuracy mandate ("jangan agree aja, bener-bener review") is that loop, applied to engineering numbers instead of secrets.

TodayA 40-test accuracy probe checks the cockpit pages — pattern-matching, not adversarial reasoning.
BuildExtend into a 3-agent loop: red attacks each numeric/content claim, blue defends with sources, synth issues a verdict. Re-use the v1.41.7 confidence_tier + claim-level provenance as evidence. Wire rz-shield.py as a pre-ship gate on calculators + cockpit pages.

Live-data layer ECC · MCP

RZ calculators run on pinned 2025 figures. ECC's MCP layer connects to live external capability. The static-safe RZ analog: a thin, cached, attribution-carrying data layer that never breaks offline.

TodayEvery calculator hardcodes a 2025 dataset. Accurate at ship, stale forever after.
Buildjs/rz-data-layer.js — fetch + cache + graceful fallback to the pinned dataset. Wire the inputs that matter: grid carbon intensity, regional energy price, weather→free-cooling hours. Every live value carries source + timestamp.
