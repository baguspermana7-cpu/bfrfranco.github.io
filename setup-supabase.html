🔒 Deploy Backend /calc — DC-OS anti-theft

Pindahkan perhitungan engine ke server (Cloudflare Worker) supaya kode math tak ikut ke browser = tak bisa dicuri. Tiap kotak ada tombol Copy. Kerjakan berurutan. Jalankan tiap perintah di terminal Claude Code pakai awalan !.

✅ Yang SUDAH beres (tak perlu diulang): Supabase schema v3 (14 tabel) + akun + RLS · engine rz-engine.js v2.4.0 (299/0) · DCMOC DC-OS + dashboard + 13-pillar UI · 3 bug capex · secondbrain. Halaman ini hanya untuk langkah terakhir: deploy backend /calc.

1 Login Cloudflare

Sekali saja. Browser kebuka → klik Authorize. (Kalau sudah pernah login, lompat ke Langkah 2.)

cd cf-worker && npx wrangler login

Kalau npx tanya install wrangler → ketik y.

2 Deploy

Bundle src/calc.js + rz-engine.js jadi satu Worker. Setelah sukses, /calc langsung aktif — math jalan di server.

cd cf-worker && npx wrangler deploy

Config sudah siap: SUPABASE_URL + anon sudah di wrangler.toml, KV sudah ada. Tak perlu set apa-apa buat deploy minimal ini.

3 Tes — pastikan jalan

Panggil engine di server. Harus balik {"ok":true,"data":0.99995,...}.

curl -X POST https://rz-finance-gateway.resistancezero0us.workers.dev/calc \
  -H "Content-Type: application/json" \
  -d '{"model":"reliability.tierTarget","args":[4]}'

Cek daftar engine yang bisa dipanggil:

curl https://rz-finance-gateway.resistancezero0us.workers.dev/calc/models

Tes CAPEX (contoh):

curl -X POST https://rz-finance-gateway.resistancezero0us.workers.dev/calc \
  -H "Content-Type: application/json" \
  -d '{"data":"capexDetail.cityCapexPerW.muscat"}'
Kalau ketiga tes balik {"ok":true,...} → backend anti-curi LIVE. Selesai. 🎉

A Opsional — Audit trail (log tiap calc)

Supaya tiap panggilan /calc tercatat di tabel audit_log Supabase.

  1. Ambil service_role key: Supabase Dashboard → Project Settings → API → baris service_role (RAHASIA — jangan share).
  2. Set sebagai secret (paste key saat diminta):
cd cf-worker && npx wrangler secret put SUPABASE_SERVICE_ROLE_KEY

Lalu deploy ulang:

cd cf-worker && npx wrangler deploy

B Opsional — Wajib login (gate JWT)

Kalau mau /calc HANYA bisa dipanggil user yang login (session Supabase valid).

Bilang ke Claude: "set REQUIRE_AUTH" — dia edit cf-worker/wrangler.toml [vars] tambah REQUIRE_AUTH = "1", lalu kamu deploy ulang (Langkah 2). Client kirim header Authorization: Bearer <token>.
