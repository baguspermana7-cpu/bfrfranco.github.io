1 WAJIB — Ganti GitHub token (bocor di URL remote)

Token PAT-mu ke-embed plain-text di URL git remote. Siapa pun yang lihat config repo bisa pakai. Ganti + revoke sekarang.

1a. Buat token baru — buka github.com/settings/personal-access-tokens → Generate new token (fine-grained) → pilih repo bfrfranco.github.io → Permissions: Contents = Read and write → Generate → copy token (mulai github_pat_…).

1b. Buang token lama dari URL remote (jadi URL bersih tanpa token):

git remote set-url origin https://github.com/baguspermana7-cpu/bfrfranco.github.io.git

1c. Simpan token baru aman via credential helper (biar tak balik ke URL):

git config --global credential.helper store

Push berikutnya akan minta: Username = baguspermana7-cpu, Password = tempel token baru (bukan password akun). Tes:

git push

1d. Revoke token LAMA (yang bocor) — github.com/settings/tokens → cari token lama ghp_… → Delete / Revoke.

Selama token lama belum di-revoke, dia masih valid. Revoke = wajib.
