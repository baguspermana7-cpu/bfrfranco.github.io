Plan 02 — Design System

Dark-mode character standard.

The current dark mode reads as generic — flat panels, static numbers, default type. This plan picks one of four on-brand characters, each with animated-on-load data viz and intuitive PC/mobile responsive, then codifies it as RZ Dark System v1 — a token system with two registers. Every section below is a live visual, not a description.

03

The system — two registers, one token set

RZ has two page families. Each gets a register of the same system — identical structure + motion + signal-semantics, different surface character. Swap with one data-rz-register attribute.

Instrument data-rz-register="instrument"

Oscilloscope character — phosphor-green/cyan, graticule grid, scanlines, JetBrains Mono display, animated traces.

  • cockpits · datahallAI · dc-conventional
  • chiller / water / fire / EPMS / ict
  • SLD & P&ID labs · market monitors

Editorial data-rz-register="editorial"

Refined report — Fraunces serif display, generous whitespace, quiet accents, eased data viz. (This page uses it.)

  • index · articles · hubs
  • plan landings (planb)
  • calculator marketing shells

04

Anti-slop checklist (every dark page must pass)

The patterns that made the old dark mode read generic — banned, with the fix.

✗ static numbers
✓ count-up / trace-in on load
✗ Inter / system font
✓ Plex + JetBrains + Fraunces
✗ Anthropic-purple accent
✓ signal tokens (amber/green/cyan/red)
✗ rounded-everything
✓ 3px instrument / 10px editorial
✗ flat dead panels
✓ graticule / wash atmosphere
✗ glassmorphism / dot-grid
✓ thin-line discipline
05

The code — one attribute swaps the whole skin

Tokens live in css/rz-dark.css. A page declares its register; everything else inherits.

/* css/rz-dark.css — two registers of one token system */
[data-rz-register="instrument"]{
  --rz-bg:#060A0D; --rz-accent:#22F5A8; --rz-accent2:#2BE8FF;
  --rz-display:'JetBrains Mono'; --rz-radius:3px;   /* graticule + scanlines */
}
[data-rz-register="editorial"]{
  --rz-bg:#0E0F12; --rz-accent:#E8B563; --rz-accent2:#6FBF9A;
  --rz-display:'Fraunces' (serif); --rz-radius:10px;  /* calm wash, no grid */
}

// animated-on-load primitive (probe-safe count-up) — applied to #p-dash in v1.43.5
requestAnimationFrame(frame);            // smooth cubic-ease 0 → value
setTimeout(settle, dur+300);             // HARD guarantee exact final value

This standard is dark-only; the existing light toggle is untouched. A light-mode redesign would be its own plan card.

08

Article skin — editorial register (content focus)

The first real-page adoption target is articles, not the cockpits. Editorial register: Fraunces serif display + italic accent, mono kickers/metadata, drop-cap, pull-quote, signal-amber callout, read-progress + staggered entrance. Body copy stays IBM Plex Sans for readability — only the editorial chrome changes. Rollout: shared `css/rz-article-dark.css`, applied per-article via data-rz-register="editorial" + a per-series accent override, batched 3–4 articles per ship after the article-26 pilot.
