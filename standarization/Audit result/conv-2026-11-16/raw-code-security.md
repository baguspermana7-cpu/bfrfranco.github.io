Method:
- Grepped all sinks: innerHTML/insertAdjacentHTML/document.write, postMessage, URLSearchParams/location, localStorage/JSON.parse, Math.random, set/clearInterval/Timeout, external `<script src>`.
- Parsed every JS file and inline `<script>` block with acorn (`scratchpad/fnlen.cjs`) to measure function lengths.
- Read the surrounding code for each candidate. Anything I could not confirm was dropped.
