# PLN Jawa Tengah + DIY Provincial Grid

Province sub-page covering Central Java + Yogyakarta. CSS prefix `pjgjt-`. Map fitBounds `[[-8.20, 108.80], [-6.50, 111.30]]`. Logo gradient amber (135deg #b45309 → #f59e0b → #fbbf24).

## Provincial Stats

- **Peak load**: 5,400 MW
- **Reserve margin**: 33 % (most generous in Java)
- **Coal share**: 71 %
- **Geothermal**: 9 %
- **Hydro**: 8 %
- **DC operators**: 3 (Edge nodes Semarang, PLN Icon+ Yogyakarta, plus 1 Tier-III TBD)
- **DC capacity**: ~25 MW IT load

## Power Plant Anchors

- **PLTU Tanjung Jati B** — coal — 2,640 MW — Jepara (largest single coal site in Java, 2006)
- **PLTU Cilacap** — coal — 1,400 MW — operated by S2P (2006)
- **PLTU Adipala** — coal — 660 MW — Cilacap (2015)
- **PLTA PB Sudirman / Mrica** — hydro — 184 MW — Banjarnegara (1989)
- **PLTP Dieng** — geothermal — 60 MW — Banjarnegara (2002)
